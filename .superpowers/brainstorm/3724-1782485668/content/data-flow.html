📊 核心数据模型

Paper {
  id: string
  title: string
  authors: string[]
  year: number
  category: string
  pdfPath: string
  summary?: AISummary
  difficulty: 'beginner' | 'intermediate' | 'advanced'
  tags: string[]
  references: string[]  // 引用的论文 ID
}

AISummary {
  abstract: string
  keyPoints: string[]
  keyConcepts: { term: string; explanation: string }[]
  prerequisites: string[]
  relatedPapers: string[]
}

🛡️ 错误处理 & 降级策略

✅ 正常模式

  • AI 摘要 + 问答完整可用
  • 知识图谱实时渲染
  • 阅读路径智能推荐

⚠️ 降级模式

  • 无 API Key 时：仅展示论文元数据 + PDF
  • AI 失败时：显示缓存结果或提示重试
  • 向量库不可用：降级为关键词搜索
