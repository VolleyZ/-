三个项目方案对比

基于 Papers We Love 仓库的 AI 论文助手，我推荐方案 A

A

⭐ PaperLens — 智能论文探索平台 （推荐）

以"知识探索"为核心的 Web 应用，四大功能全覆盖

技术栈：Next.js + TypeScript + TailwindCSS + LangChain.js
核心亮点：交互式知识图谱 + AI 对话 + 阅读路径推荐
首期范围：标准版（摘要 + 问答 + 推荐 + 知识图谱 + 笔记）
B

PaperCompanion — 极简阅读助手

轻量专注，PDF 阅读器 + AI 侧边栏，阅读体验优先

技术栈：Vue 3 + Vite + FastAPI (Python)
核心亮点：在线 PDF 阅读 + AI 摘要/问答同步
首期范围：精简版（论文浏览 + AI 摘要 + 侧边栏问答）
C

PaperGraph — 知识图谱优先

以图谱可视化为主，探索论文关系网络

技术栈：React + D3.js + Neo4j + Python 后端
核心亮点：力导向图 + 主题聚类 + 引用分析 + 演进路线
首期范围：图谱探索 + 论文详情 + 简单摘要
💡 我的推荐：方案 A (PaperLens)
理由：功能最完整（覆盖你想要的 ABCD）、Next.js 全栈开发效率高、知识图谱+AI 助手有差异化、可分阶段迭代、社区生态好。
