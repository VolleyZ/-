PaperLens — 产品架构总览

智能论文探索平台：AI 驱动的计算机科学知识导航

🏗️ 系统架构

PaperLens 技术架构
🎨 前端层：Next.js + TypeScript + TailwindCSS
▲
⚙️ API 层：Next.js API Routes / tRPC
▲
🤖 AI 服务层
LangChain.js + 多模型适配
📚 论文数据层
本地 PDF + 元数据索引
🗄️ 数据存储
SQLite + 向量数据库

🎯 四大核心功能模块

📝 智能摘要 & 解读
自动提取核心观点、通俗解释、关键公式/算法解读
🛤️ 阅读路径推荐
按主题/难度生成学习路径，前置论文推荐
💬 AI 问答对话
针对论文内容提问，上下文理解，延伸讨论
🔗 知识关联图谱
可视化论文关系、引用网络、主题聚类

📁 项目结构

paperlens/
├── apps/web/            # Next.js 前端应用
│   ├── app/            # App Router 页面
│   ├── components/   # UI 组件
│   └── lib/            # 前端工具函数
├── packages/ai/       # AI 服务层 (LangChain)
│   ├── models/       # 多模型适配器
│   ├── prompts/     # Prompt 模板
│   └── chains/       # 处理链
├── packages/core/    # 核心业务逻辑
│   ├── paper/        # 论文解析 & 索引
│   ├── graph/        # 知识图谱构建
│   └── path/         # 阅读路径算法
└── data/             # 论文数据 & 数据库
